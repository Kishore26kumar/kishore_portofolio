How I think in DAX

Time intelligence is where dashboards earn their keep. This is the shape of the year-over-year measure behind my retail report.

// Year-over-Year Revenue Growth
YoY Growth % =
VAR Current = [Total Revenue]
VAR Prior =
    CALCULATE(
        [Total Revenue],
        SAMEPERIODLASTYEAR( 'Date'[Date] )
    )
RETURN
    DIVIDE( Current - Prior, Prior )

Same toolkit, different questions: MTD, QTD, YTD, MoM and DATEADD for comparing periods, CALCULATE, FILTER and ALL for controlling context, DIVIDE so a zero never breaks a card.

Behind every measure sits a clean model: Power Query for the shaping, a star schema for the relationships, SQL and Pandas for the groundwork.
